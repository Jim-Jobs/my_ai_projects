      人生墓碑 · 产品需求文档

      轻量娱乐型微信小程序 · 用 AI 生成"毒舌但治愈"的搞笑墓碑卡片

      要解决的问题

      年轻用户需要低成本、无负担的"自黑式解压"和可分享的社交素材。现有娱乐型 AI 应用集中在聊天伴侣、算命、头像写真、AI 绘画，缺少用"荒诞 + 毒舌文案"对个人经历做二次加工与总结的玩法。用户缺的不是"更聪明的 AI"，而是一个好笑、被戳中、想晒给朋友的情绪出口。

      产品目标

      • 用户 30 秒内生成一张搞笑墓碑卡片，并愿意保存或转发。
      • 用纯文本 AI 能力控制单次成本，支撑"免费玩 + 爆量不亏"。
      • 以"给朋友立碑"作为裂变钩子，驱动熟人圈传播。

      主要用户

      18–30 岁微信用户，有自嘲 / 玩梗习惯，活跃于熟人社交圈；无账号、无需登录，即开即玩。

      核心任务与完成条件

      核心任务：输入「性格标签 + 经历」或「朋友信息」→ 生成墓碑卡片 → 保存 / 分享。
      完成条件：出现一张包含「墓志铭 + 人生高光回顾 + 亲友寄语」的可保存卡片。

      P0 范围（最小闭环）

      • 模式选择（给自己 / 给朋友立碑）
      • 输入（标签多选、经历文本、一键随机；朋友昵称 + 特点）
      • AI 生成（含加载、失败重试）
      • 结果卡片展示
      • 保存图片与转发分享

      假设

      • [Assumption] 文本大模型 API 单次生成成本约 2–3 分钱，可支撑免费体验。
      • [Assumption] 变现方式（激励广告 / 会员去广告）[TBD]，MVP 阶段不实现。
      • [Assumption] MVP 无账号体系，生成结果仅保存在本次会话内。

      设计说明

      核心旅程

      1. 打开小程序 → 首页，选择「给自己立碑」或「给朋友立碑」。
      2. 填写标签 / 经历（或一键随机），点击生成。
      3. 进入加载态，AI 返回结构化结果。
      4. 展示墓碑卡片（墓志铭 / 高光回顾 / 亲友寄语）。
      5. 保存图片或转发，闭环完成。

      关键产品决策

      决策理由
      文案是核心资产产品 80% 的成败取决于 AI 毒舌文案是否"损中带暖"，prompt 需重点打磨，基调定为自黑式解压而非纯丧。
      "给朋友立碑"是裂变钩子输入朋友信息生成卡片并 @TA，是转发率的关键；v1.0 即纳入 P0，但文案强制"夸损参半"防止冒犯。
      墓碑视觉用前端 canvas 绘制记忆点强、秒出图，且避免图像生成 API 的高成本与慢速。
      只用文本大模型单次 2–3 分钱，支撑爆量不亏。

      对象模型：墓碑卡片

      字段说明来源
      模式自己 / 朋友用户选择
      主角名"我" 或 朋友昵称输入
      墓志铭一句话，≤30 字AI 生成
      人生高光回顾3–4 条，每条 ≤25 字AI 生成
      亲友寄语按关系 3 条，每条 ≤25 字AI 生成

      角色与权限

      单一角色（访客，无登录）。无账户、无历史记录、无管理后台；所有操作本地会话内完成，不涉及权限分层。

      功能需求详情

      点击左侧原型中的元素可跳转到对应需求；需求 ID 两侧一一对应。

      F1 · 首页与模式选择

      目的：让用户 1 秒进入两种核心玩法。

      流程：进入小程序 → 显示首页（标题、slogan、两个主按钮、案例卡片）→ 点「给自己立碑」进入 F2，点「给朋友立碑」进入 F3。

      规则：

      • 默认高亮「给自己立碑」作为主操作。
      • 案例卡片仅展示，可点「换一批」轮换两套示例，不触发生成。
      • 首次进入无历史记录，直接显示首页，无需登录。

      边界：无网络时首页仍可展示（静态），点生成时才提示失败。

      F2 · 给自己立碑：输入

      目的：收集生成卡片所需的个人特征。

      字段：

      字段类型规则
      性格标签多选预置 12 个；可多选但 ≤5 个；超过 5 个时拒绝新选并提示
      经历 / 口头禅文本（可选）≤50 字，可留空

      处理规则：

      • 未选任何标签时点「生成」→ 显示行内提示"至少选 1 个标签，或点一键随机"，不发起请求。
      • 「一键随机」随机选中 3 个标签并填入一条随机经历，覆盖当前已填内容。

      状态：空态（未选标签）→ 提示随机；有效态 → 可生成。

      F3 · 给朋友立碑：输入

      目的：输入朋友信息生成 TA 的墓碑卡片。

      字段：

      字段类型规则
      昵称文本（必填）≤12 字；为空时「给 TA 立碑」被拦截并提示
      特点 / 梗文本（可选）≤50 字
      关系单选死党 / 同事 / 对象 / 亲戚，默认死党；决定寄语口吻

      规则：该模式文案基调强制"夸损参半"，禁止纯贬损或人身攻击，见 R3 内容安全。

      F4 · 生成处理

      目的：调用 AI 生成卡片内容的过渡与失败处理。

      流程：提交 → 显示加载态（轮换解压文案）→ 成功进入 F5 / 失败显示错误与「重试」。

      规则：

      • 请求超时 10 秒判定失败。
      • 失败时保留用户已填输入，点「重试」重发。
      • 重试上限 3 次；仍失败则提示"稍后再试"并返回输入页。

      状态：loading / 成功 / 失败（可重试）。

      F5 · 结果卡片

      目的：展示生成结果，让用户"被戳中、想晒"。

      内容：墓志铭（1 句）、人生高光回顾（3–4 条）、亲友寄语（3 条）。字段规则见 R1。

      规则：

      • 结果仅保存在本次会话内存，退出小程序不保留（MVP 无账号）。
      • 「重新生成」回到 F4 重新生成，但保留原输入不变。

      F6 · 保存与分享

      目的：把卡片转为图片并触发传播。

      流程：点「保存图片」→ 前端 canvas 绘制卡片 → 存入相册；点「分享」→ 转发卡片 / 小程序链接。

      规则：

      • 保存失败（相册权限被拒）→ 提示并引导授权后重试。
      • 分享即完成核心闭环，无额外门槛。

      边界：无授权、无账号，分享是唯一可观察的完成信号。

      共享规则

      R1 · 卡片字段规则

      字段长度数量基调
      墓志铭≤30 字1 句毒舌但治愈，金句感
      人生高光回顾每条 ≤25 字3–4 条荒谬、自黑、反差
      亲友寄语每条 ≤25 字3 条按关系口吻，夸损参半

      R2 · 卡片状态机

      当前状态触发下一状态反馈
      输入中点击生成（校验通过）生成中加载态
      生成中AI 返回成功成功展示卡片
      生成中超时 / 失败失败错误提示 + 重试（≤3）
      失败点重试生成中重新请求
      成功点重新生成生成中保留输入重新请求

      R3 · 内容安全规则

      • 文案基调固定为"自黑式解压"，禁止暴力、自伤/自杀倾向、歧视、涉黄内容。
      • "给朋友立碑"强制"夸损参半"，禁止纯贬损、人身攻击、外貌羞辱。
      • "墓碑"主题做轻处理：定位为"人生阶段总结"的梗，而非真实死亡；可在首页副标题弱化"墓碑"字样。
      • 所有 AI 输出需过微信内容审核，并加 prompt 级硬约束兜底。

      R4 · 输入边界汇总

      字段必填上限默认值
      性格标签否（一键随机兜底）5 个空
      经历 / 口头禅否50 字空
      朋友昵称是12 字空
      朋友特点 / 梗否50 字空
      关系是（有默认）—死党

      R5 · AI 生成指令（Prompt 初稿）

      文案是产品核心资产，以下为配套 R3 的生成指令初稿，供后端调模型时直接使用：

      你是「人生墓碑」的文案主笔，专长是把普通人的小毛病写成一针见血、又好笑又暖的段子。

【任务】根据用户输入生成一张"墓碑卡片"的内容，严格输出 JSON，不要输出任何额外文字或解释。

【输入变量】
- 模式 mode：self（给自己）/ friend（给朋友）
- 主角名 name
- 性格标签 tags：数组
- 经历/口头禅 experience：可为空
- 关系 relation：仅 friend 模式（死党/同事/对象/亲戚）

【输出 JSON 结构】
{
  "epitaph": "一句话墓志铭，≤30字",
  "highlights": ["高光回顾1","高光回顾2","高光回顾3","高光回顾4"],
  "comments": ["寄语1","寄语2","寄语3"]
}

【文案基调】
1. "毒舌但治愈"：损得要准，但落脚点是暖，让人会心一笑而非难堪。
2. "荒谬化"：把日常小毛病夸张成史诗级成就，制造反差。
3. 金句感：墓志铭要能单独截图传播。
4. 必须贴合用户给的标签和经历，禁止套用万能模板。

【硬性约束（违反即不合格）】
- 禁止暴力、自伤/自杀倾向、歧视、涉黄、政治内容。
- friend 模式必须"夸损参半"：每条贬损都需搭配一个优点或夸赞，禁止纯贬损、外貌羞辱、人身攻击。
- 不输出任何与"真实死亡"相关的沉重内容，只玩"人生阶段总结"的梗。

【亲友寄语口吻映射】
- 死党：损友式，互怼但护短
- 同事：职场吐槽式
- 对象：又爱又恨式
- 亲戚：催婚/关心式

【示例】
输入：mode=self, name=我, tags=[拖延晚期,熬夜冠军], experience=口头禅"再睡五分钟"
输出：
{
  "epitaph": "这里躺着一位'明天再说'冠军，把每个 deadline 都活成了惊悚片。",
  "highlights": ["早起 flag 立了 17 次，成功 0 次", "凌晨三点下单的外卖比白天还多", "把'再睡五分钟'重复了二十年"],
  "comments": ["妈妈：这孩子哪都好，就是不爱回消息。", "老板：永远在'马上就好'的路上。", "死党：我作证，他的人生只有表情包是真的。"]
}
